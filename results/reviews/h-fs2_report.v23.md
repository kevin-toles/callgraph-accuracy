## Systematic patterns (scripted census, `h-fs2_r23_census.py`; union 216)
1. **P3: members reached through a self-type or companion-platform trait are misnamed. 49 edges.** In traits declared `{ self: X.type => }`, names of X's members are emitted three ways. Some get an unqualified `Name#m` at medium (`Builder#from*` 17, `AsyncProviderBasedNetwork#<init>` 3, `AsyncUnixSockets#<init>` 3, `SocketBuilder#apply` 2, `AsyncNetwork`, `AsyncBuilder`, `UnsealedTLSContext`). Some get an invented `cats.syntax.all.X#m` (9). Others are named on the companion, although the member is defined in the platform trait the companion extends (`Hasher#apply`, `TLSSocket#apply` ×2, `Socket.BufferedReads#<init>` ×2, `Socket.AsyncSocket#<init>`, `Chunk.IArraySlice#<init>`, `SocketOption.Key#get/set` ×4). The scanned nodes exist (`fs2.CollectorPlatform.BuilderPlatform#fromTraversableFactory`, `fs2.io.net.tls.TLSContext.SocketBuilder#apply`), so each should be that ID at high. Validated by hand on 8 edges. The tool is inconsistent here: `SocketInfo.forAsync` → `SocketInfoCompanionPlatform#forAsync` (sample #13) is resolved correctly.
2. **P2: locals bound to a call with a scanned declared return type stay low. 30 edges.** These are the 2026-11-12 let-bound ruling and typed call results. `val b = makeArrayBuilder[Any]` (declared `: ArrayBuilder[A]`) leaves `b.sizeHint`/`b.result` low (23 edges in Chunk.scala and Stream.scala). Also `val bb = toByteBuffer[B]` (5), `val t = withRate(over)(f)` (3), `val thisNames = this.names` (1) and `val read = readInputStream(...)` (1). Lower bound: the script only matches simple right-hand sides.
3. **P4: anonymous subclasses of a trait or interface get a constructor edge. 23 edges.** Scanned traits: `GroupMembership` 4, `UnsealedTLSContext` 3, `UnsealedTLSSocket` 2. ## Spec gaps (counted separately, not wrong)
- **Case-class apply without `new` (CAPABILITIES scala/16). 331 edges**, emitted `T#<init>` constructor high. Example: `def pure[F[_], R](r: R): Pull[F, Nothing, R] = Succeeded(r)` (Pull.scala:370, `private final case class Succeeded`). Open question: is it data construction, `T#<init>`, or the synthesized `T#apply`?
- **Calls to members of an anonymous class from inside it. 146 low bare edges.** Example: `.flatMap(deflater => _deflate(deflateParams, deflater, crc32 = None)(stream))`, where `_deflate` is a `private def` inside `new Compression.UnsealedCompression[F] {`. Open question: SPEC folds anonymous-class members into the enclosing function, but it does not say what callee ID a call to such a member gets.
- **Statements in a class or object body (scala/17). 79 edges**, given caller `T#<init>`/`T#<clinit>`. Examples: `require(value >= Pid.MinValue && value <= Pid.MaxValue)` (Pid.scala:33) and `s2n_init()` (S2nConfig.scala:47). Open question: is the caller `T#<init>`/`<clinit>` or the type ID?
- **Type-ascription receivers. 32 edges**, emitted `.m` low. Example: `(out: Buffer).flip()`. Open question: does `(x: T)` type its receiver as `T` for decision A, or is it a computed receiver?
- **Extension methods from implicit classes on typed receivers. 10 edges.** Examples: `bb.hasArrayBuffer()` (`TypedArrayBufferOps._`), `slice.values.atUnsafe(slice.offset)` (sample #30) and `sock.registerListener[F, js.Error]("error", dispatcher)`. Open question: what ID does a method added by an implicit conversion get (the implicit class's member, the receiver type's, or a guess)?
- **Compound-type receivers. 4 edges.** Example: `javaList.get(i)` with `javaList: ju.List[O] with ju.RandomAccess`. Open question: which component of an intersection type names the method?
- **Bare calls of members inherited from an external class by an anonymous subclass. 3 edges.** Example: `setState(1)` in `new AbstractQueuedSynchronizer {` (Synchronizer.scala:35). Open question: the rule says to name such a call by the calling type, but the calling type is anonymous.
- **Application of a non-function value. 3 edges.** Examples: `pre(0)` and `lengths(k - 1)` on a Chunk or Array, emitted as a low bare `pre`. Open question: is `x(i)` on a value whose type defines `apply` a call of `T#apply`, a callback through `x`, or no edge?
