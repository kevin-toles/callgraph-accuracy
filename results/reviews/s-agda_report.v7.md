## Systematic patterns (scripted counts, union = 678)
1. **MagicHash names typed `method`: 324.** Every in-scope `method` edge (228 low, 90 high, 6 medium) has a callee ending in `#` (`isTrue#`, `indexWordArray#`, `Agda.Utils.Word.uncheckedClearBitWord#`, `GHC.Exts.eqWord#`). None is `T#m`, so per the direct/method ruling each should be `direct`. The callee and tier are otherwise unaffected. Script: `s-agda_r7_census.py` (asserts that all method callees end in `#`).
2. **Re-export of `Text.PrettyPrint.Annotated` through `Agda.Syntax.Common.Pretty` not followed: 271.** These are low bare names in files that import `Agda.Syntax.Common.Pretty` unqualified (or with a list that names them) and have no other provider: `text` 164, `nest` 77, `render` 21, `hang` 7, `renderStyle` 1, `cat` 1. The expected callee is `Text.PrettyPrint.Annotated.<name>`, medium. The tool emits exactly that for the same import in Syntax/Concrete/Pretty.hs and Compiler/MAlonzo/Pretty.hs (C2). Script: `s-agda_r7_resolve.py`, a re-export-following resolver over module headers and import lists. I excluded the 23 edges in `Agda/Syntax/Common/Pretty.hs` itself, which imports the external module directly beside another unlisted external import. Hand-checked in Types.hs, Common.hs, Interaction/Library/Base.hs, Syntax/Scope/Base.hs, Syntax/Internal.hs and TypeChecking/Errors.hs (explicit `( prettyShow, render )`): none defines the name locally.
3. **Invented external IDs from the "one unlisted external import" fallback: 46.** The tool assigns a name to an external module that does not export it, when the name really comes from a `Class(..)` import list, a scanned re-export or a qualified export entry: `Data.Strict.Tuple.*` 14, `Control.Monad.{funClauses,conPars,conSrcCon,dataCons,recConHead,funMutual,funProjection,put}` 8, `Control.DeepSeq.{several,insideAndOutside,restrictTo}` 7, `System.IO.liftIO` 5, `System.Console.ANSI.liftIO` 4, `Data.Peano.*` 3, `GHC.Exts.{local,put}` 3, `Data.Void.tell` 1, `Text.PrettyPrint.Annotated.toVertex` 1. Script: `s-agda_r7_census.py`, built from a list of (module, name) pairs I checked by hand against every medium external callee listed per module.
4. **Instance method's own name, called inside its infix-defined body, emitted as a callback: 37.** These are the cases where the callee equals the caller's last segment: `compare` 28, `meet` 5, `hashWithSalt` 2, `notWorse` 1, `compose` 1. The callee should be the class method (for example `Prelude.compare`, medium, direct). Script: `s-agda_r7_infixdef.py`. I hand-checked all 37 lines it printed.
