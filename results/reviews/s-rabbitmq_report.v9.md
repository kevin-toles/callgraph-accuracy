- **Precision:** 50 edges, seed `20261113`, stratified by tier: high 17, medium 23, low 5, unknown 5. They come from 50 distinct files. All 50 are correct for call, caller, callee, tier, call_type and line. Notes on particular items:

  - Guards (`when is_number(arg)`) are `Kernel.is_number`, per Decisions 2026-10-29 for Elixir.
  - Calls on a module held in a variable (`command.switches()`, `formatter.format_output(...)`) are `recv.m`, low, method.
  - Calls of a function value (`step.()`, `fun.(other, acc)`) have the variable as callee, callback, unknown.
- **Recall:** three functions in three files:

  - `RabbitMQ.CLI.Plugins.Helpers.write_enabled_plugins` (plugins/plugins_helpers.ex:351–371): 8 of 8 found.
  - `RabbitMQ.CLI.Ctl.Commands.StatusCommand.result_map` (ctl/commands/status_command.ex:246–287): 37 of 44 found. The 7 missed are all `|> to_string`.
- **Census scripts.** Each was hand-checked on a few hits.
  - Every high callee is in `nodes`.
  - Every high same-module callee has a `def`/`defp` in its file.
  - Every bare high cross-module callee is backed by an `import`, including the `import A.{B, C}` form.
  - Alias expansion of all 1,709 qualified calls agrees with the file's `alias` lines. The two apparent misses are Elixir's own `File` inside the top-level module `RabbitMQ.CLI.Printers.File`, which the tool resolved correctly.
  - No medium edge shadows a local or imported definition.
  - There are no edges on typespecs (`String.t()`), on `&f/1` captures, or on record macro uses (`listener(node: n)`, `cell(...)`, `hostent(...)`, which are correctly silent per Decisions 2026-11-10 on records).
  - Every remote call written with parentheses (2,189) and every bare call written with parentheses has an edge. The only lines without an edge are typespecs, strings, sigils and record uses.
  - The 7 module-body edges plus the 1 file-level edge (`config/config`) have the module or the file path as caller.

## Spec gaps
- **34 edges.** In lib/rabbitmq/cli/core/doc_guide.ex, lines 35 onward of the form `Macros.defguide("access_control")` are invocations, in a module body, of a macro the scan defines (`defmacro defguide` in `RabbitMQ.CLI.Core.DocGuide.Macros`). The tool emits them as `RabbitMQ.CLI.Core.DocGuide.Macros.defguide`, high, direct, with the module as caller. SPEC does not say whether invoking an Elixir macro is an edge, or whether its call_type is `direct` or `macro`; the `macro` call_type is defined only for C/C++/ObjC/Rust. CAPABILITIES.md lists the same question as undecided (`elixir/12-quote-blocks`). The 175 medium calls of the functions this macro generates (`DocGuide.access_control()` and so on) are decided by "Generated functions have no written body". I judged them correct and did not count them here.
