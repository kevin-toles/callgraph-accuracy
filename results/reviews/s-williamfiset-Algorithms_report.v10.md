## Spec gaps (counted separately, 40 edges plus one ID question)
1. **Functional-interface calls: 21 edges** (`BinaryOperator#apply` 13, `GenericSegmentTree.Ruf#apply` 4 high, `DoubleFunction#apply` 3, `Comparator#compare` 1). Example: `dp[i][j] = minFn.apply(leftInterval, rightInterval);` with `private BinaryOperator<Long> minFn = (a, b) -> Math.min(a, b);`. Open question (CAPABILITIES java/18): is a call through a parameter, local or field whose declared type is a functional interface the decision-A typed call (`java.util.function.BinaryOperator#apply` medium, or the in-scan `Ruf#apply` high under the body-less-declaration rule), or the callback rule's `minFn`, callback, unknown?
2. **Cast-expression receivers: 9 edges** (`.compareTo` 8 in the four `MinIndexedDHeap` copies, `.id` 1). Example: `return ((Comparable<? super T>) obj1).compareTo((T) obj2) < 0;`. Open question: "Typed call results" types a receiver that is a call result, index or literal, and the 2026-11-17 ruling types a parenthesized `(new T())`. Is a parenthesized cast `((T) x)` also typed by its target type, or does it stay `.m` low?
3. **Assignment-expression receivers: 2 edges.** `while ((path = getAugmentingPath()).size() != 0) {` (MinCostMaxFlowJohnsons.java:66, MinCostMaxFlowWithBellmanFord.java:36). `path` is declared `List<Edge>` and `getAugmentingPath()` has an in-scan declared return type. 4. **Call result whose declared return type is a bounded class type parameter: 7 edges** (SplayTree.java:105, 134, 201, 204, 209, 219, 222). Example: `if (root.getData().compareTo(key) > 0) {` with `public T getData()` in `BinaryTree<T extends Comparable<T>>`. Open question: the let-bound ruling says "a generic … return type leaves the call a low guess", but decision A says "a type variable resolves to its declared bound". Does a call result of declared type `T` take T's bound (`java.lang.Comparable#compareTo`, medium), as the tool does for parameters and fields typed `T`, or stay `.compareTo` low?
